# Security policy

This repository is a public archive of optical scheme files (`scene.json`, previews, metadata). It is not the Loomrume application.

## Product or website vulnerabilities

Report them on [loomrume/lantern](https://github.com/loomrume/lantern). Use a [private vulnerability report](https://github.com/loomrume/lantern/security/advisories/new) if that form is available. Do not open an issue here — Issues are disabled.

## This archive

Merged entries are public and licensed [CC BY 4.0](LICENSE). Do not include secrets, credentials, or personal data in `scene.json` or `meta.json`.
