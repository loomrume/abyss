# Contributing

This repository is the **Abyss**: a public archive of community optical schemes for [Loomrume](https://www.loomrume.com).

## Submit a scheme

1. **Studio** — in Loomrume, **Share → Abyss**. That opens a pull request with `entries/<slug>/`.
2. **By hand** — add `entries/<slug>/` with `scene.json`, `preview.jpg`, and `meta.json`. See [entries/README.md](entries/README.md).

CI validates entries on the PR. Use the pull request checklist.

Do not edit someone else's merged entry in the same PR as a new submission.

## License

Schemes you submit are offered under [CC BY 4.0](LICENSE). Keep secrets out of `scene.json`.

## Bugs and product ideas

Issues are disabled on this repository. Open them on [loomrume/lantern](https://github.com/loomrume/lantern).
